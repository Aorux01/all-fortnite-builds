## 📌 About

This repository gathers Fortnite builds by chapter, season and version, with several mirrors per build whenever possible. Builds are Windows clients hosted by the community.

If **Epic Games** has any questions regarding this repository, please contact [@aorux01](#) on Discord. To **suggest or send builds**, contact me the same way.

## 🚀 Quick start

1. Find your build in the [navigation table](#-quick-navigation) and open its season.
2. Pick a mirror (**Fortforge**, **Reboot**, **FN-Archive**… the label shows the host) and download the archive.
3. Extract it, then launch it with a compatible launcher (see [Playable events](#-playable-events) for recommendations).
4. Always verify file integrity before running a build.
